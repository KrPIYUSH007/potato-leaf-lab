# Potato Leaf Lab

Custom CNN and InceptionV3 + SVM experiments for seven-category potato leaf classification.

## Current status

Phase I research and scope preparation. No model has been trained and no project accuracy has been measured.

Read [the Phase I research and scope package](PHASE_I_RESEARCH_AND_SCOPE.md) for the primary paper, dataset, objectives, evaluation plan, proposed responsibilities and pending guide decisions.

The next phase is environment verification, dataset download and audit, and frozen train/validation/test partitions. The Streamlit interface and training code have not yet been implemented.
